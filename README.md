### 📝 Description
Saghiri is an IoT-powered child healthcare ,designed for infants aged 0 to 3years.
It continuously tracks vital signs via smart wearables, predicts health issues like fevers,
and analyzes baby cries using AI. Additionally, it helps parents manage their child's healthcare
by tracking vaccination schedules, managing doctor information, and setting medical appointment reminders.
